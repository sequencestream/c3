# 0048 — 发送者隔离且有界的机器人 IM 可见上下文:允许的本地持久化例外

- **Status:** accepted
- **Date:** 2026-08-21

## Context

IM 聊天机器人若以群级共享 agent 会话续接,同一群中的发送者可以读取或引用他人的历史——这是跨用户
信息泄漏,且会在后续逐次授权落地前留下可被旧上下文绕过的路径。

连续对话又要求可恢复上下文。把恢复事实源放在 `~/.c3/robots/<name>` 或厂商原生会话目录,会使目录
删除/重建改变归属,并抬高后续身份模型迁移成本。把正文写入审计表则与 ADR-0046「审计只记发生、不记
内容」冲突。

ADR-0045 / SEC-2 曾断言原始 prompt 与对话转录一律不落盘。机器人若要在本机恢复 IM 可见往来,必须
先裁定一类**有界、可复核**的例外,而不是在机器人域内悄悄改写禁令。

## Options considered

- **A. 继续群级共享会话,仅靠出站守卫** —— 被否决。泄漏发生在模型上下文,不在外发文本。
- **B. 以厂商原生 `sessionId` 为唯一恢复事实源** —— 被否决。目录删除、vendor 切换、进程重启都会丢
  失归属;也无法按发送者切开旧共享会话。
- **C. 推测迁移旧共享 transcript 到某一发送者** —— 被否决。无法证明旧上下文属于谁;错误归属比切断更糟。
- **D. 把正文写入 `im_robot_turns` 审计** —— 被否决。审计回答「谁在何时触发了什么结局」,不应变成
  转录存储。
- **E. 发送者隔离 Conversation + 独立 Context Turn 表,安全切断旧共享会话** —— 采纳。

## Decision

### 允许的持久化类别

**发送者隔离且有界的机器人 IM 可见上下文**是被允许的本地持久化例外。它有限取代 ADR-0045 对「对话
转录一律不落盘」的禁止,**仅**适用于本 ADR 定义的机器人路径;工作区记忆裁决及其它会话种类的禁存
规则保持有效。

SEC-2 收敛为:原始 prompt 与对话转录默认不落盘;唯一例外是本 ADR 定义的机器人 IM 上下文。例外必须
同时满足下列保障,缺一不得写入:

1. **四维归属** —— Conversation 身份为 `(platform, robotId, threadKey, senderId)`。`senderId` 是
   平台不透明外部标识,不是 c3 用户,不跨平台合并。
2. **成对结构** —— 只存通过入站守卫的用户文本,与平台确认投递的最终 assistant 文本;同事务提交。
   思考、工具调用/结果、文件内容、被出站守卫拦截的回答不落库。
3. **凭据形状拒绝** —— 入站复用 `detectCredentialShape`;命中则不运行、不存正文,固定拒绝说明且不回显。
4. **单条与总量上限** —— 用户/assistant 各最多 4000 个 Unicode 码点;每 Conversation 最多 50 个已提交
   回合。
5. **固定保留期与确定删除** —— 自提交起最多 30 天;超出容量或保留期即硬删除完整回合(不软删、不摘要、
   不拆对)。删除机器人时级联清理。

该项例外允许已投递消息中的普通代码片段(代码问答是机器人用途之一);不放宽工具 I/O、推理、文件内容
或运行日志的禁存。凭据形状检测只能覆盖已知格式,散文秘密是本机、有界、按发送者隔离下接受的剩余风险。

### 恢复与缓存

数据库是恢复事实源。厂商原生 `sessionId` 只是同 Conversation、同 vendor、与已提交修订一致时的续接
缓存。缓存缺失、vendor 变更、运行目录删除或未提交回合失败后,均从已提交 Context Turn 启动新原生会话。
禁止按工作目录枚举、猜测或接管会话。

### 旧共享会话

旧群级 `im_robot_threads.session_id` **安全切断**:不复制到任一发送者 Conversation。升级后每个发送者
首次命中旧线程时创建空 Conversation。审计行保留,不用于反推上下文。迁移失败则不得启动 supervisor。

### 审计仍不存正文

`im_robot_turns` 继续只记元数据与结局(含 `input_rejected` 及封闭原因 `credential | too_long`)。
正文只存在于受本 ADR 约束的 `im_robot_context_turns`。

## Consequences

同一群中不同发送者不能共享连续对话;需要共同背景时须在各自消息中显式提供。升级后首条消息开启新
上下文,旧历史不可恢复——这是切断的代价。

备份、迁移与删除机器人时必须连同 Context Turn 处理。数据库不可用时不得降级到目录或厂商会话扫描。

## Compliance

- 违反信号:群级共享可恢复上下文;审计表出现正文;Context Turn 缺少四维归属或成对提交;超限仍写入;
  软删/摘要半个回合;从工作目录扫描恢复会话;旧共享 `session_id` 被赋给某一发送者;迁移失败仍启动
  supervisor;非机器人会话写入同类转录。
