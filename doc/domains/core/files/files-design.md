# files — 设计

实现[规格](files-spec.md)。本域拥有已登记工作区内的只读检视，不拥有运行循环、权限待决或工作区目录。

## 协作

**session-registry.** 以已登记工作区名解析根路径。本域不接受客户端路径作为信任根，也不解释名称到路径之外的映射。相对路径的守卫在本域，见 [SEC-11](../../../non-functional/security.md)。

**agent-session.** 就代码提问复用普通工作会话（`create_session` / `select_session`），不另开种类或路由。浏览失败不影响会话；会话失败不开放本域写。

**web-console.** 渲染树、状态与内嵌会话。浏览器只持有工作区相对路径。

## 关键取舍

**只读检视，写走会话。** 浏览永不改盘。提问与改代码走既有工作会话和权限网关，避免为本域开一条写通道。

**状态失败为空，不打断树。** 非 git 或读不到则空快照。缺标记优于让整页失败。

**不扫密钥。** 工作区所有者查看自己的树；`.env` 等非 `.git` 文件可读（FILE-R8）。密钥扫描会把检视做成策略引擎。

## 非功能

读与搜索有界。错误按请求隔离，不影响智能体会话或其他工作区。
