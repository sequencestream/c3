# files — 数据模型

实体与不变量。行为见[规格](files-spec.md)，协作见[设计](files-design.md)。线上形状在[共享协议](../../../shared/api-conventions/websocket-protocol.md)中定义，此处不重复。

## 已登记工作区

files 所见的工作区。浏览器只持不透明身份；文件系统根只在服务端解析。

## 相对路径

在该工作区下解释的路径。不是绝对路径；解析后离开根则拒绝。

## 目录项与文件观察

目录列出直接子项，种类为文件或目录。一次读取给出元数据，文本内容仅在非二进制且未超限时存在。

## 工作树状态

只读快照：改动、暂存、未跟踪。改动与暂存可同时成立。缺省（非 git、读失败或干净）即无标记。不表示提交、blame 或版本间 diff。

## 内嵌工作会话

文件页绑定的普通工作会话，用于就代码提问。身份与生命周期由会话域拥有；本域只决定文件页指向哪一个。
