# Domain: agent-config

- **Group:** settings
- **One-line:** 智能体档案、具名上游、默认与专用路由、按会话绑定。
- **Owner:** maintainer
- **Status:** active
- **Depends on:** [system-setting](system-setting.md)(CLI 版本与宿主是否可跑);[workspace-setting](workspace-setting.md)(工作区覆盖);[auth](../core/auth.md)(改全局配置过管理员门)。
- **Depended on by:** [agent-session](../core/agent-session.md)(启动解析与同厂商候选);[session-registry](../core/session-registry.md)(绑定与厂商冻结);[web-console](../core/web-console.md)(设置页、新建与冷启动门);[sandbox](../core/sandbox.md)(连接是否为空决定钥匙串);[automations](../core/automations.md)(默认与专用智能体);[discussion](../core/discussion.md)(启用池与组织者缺省);[im-robot](../core/im-robot.md)(厂商与智能体)。
- **exposes-api:** true — WebSocket `/ws`。消息形状在[共享协议](../../shared/api-conventions/websocket-protocol.md)中定义。
- **ADRs:** [0015](../../architecture/adr/0015-session-agent-binding-vendor-ownership.md) 双键绑定与冻结厂商、[0029](../../architecture/adr/0029-vendor-neutral-relay-and-agent-group-failover.md) 中立 relay 与组回退、[0012](../../architecture/adr/0012-host-binary-probe-first-capability-gate.md) 宿主 CLI 门控

本域拥有智能体注册表、具名上游、系统默认与角色路由、按会话绑定。运行循环见 [agent-session](../core/agent-session.md);CLI 版本见 [system-setting](system-setting.md)。不渲染设置页。

## Overview

agent-config 管理会话据以启动的**智能体**:厂商无关的档案,加上可选的具名上游、系统默认、按角色的专用路由,以及按会话的绑定。厂商决定启动哪个客户端;连接来自所引上游或该厂商 CLI 登录,与厂商正交。模型始终是独立覆盖。注册表永不为空,且恰好一个系统默认。

运行时消费见 [agent-session](../core/agent-session.md),不复制其规则。权限模式与讨论轮次属 [workspace-setting](workspace-setting.md)。宿主 CLI 版本属 [system-setting](system-setting.md)。

**范围:** 档案与顺序、具名上游、连接解析与探测/测速、分组与回退、运行时门控、一键自动配置、默认与专用路由、每会话绑定。
**边界:** 不驱动运行循环;不持有 CLI 版本;不持有工作区权限模式与讨论上限;不持有权限状态;不渲染 UI。

## Business rules

### 智能体档案

- **AC-R1** — 无受保护单例。每个智能体可删可改。id `'system'` 只在注册表空时作为合成兜底(AC-R3)。
- **AC-R2** — 系统默认必须指向存在且已启用的智能体。未知、已删或已禁用时,**存储时**改写为顺序上下一个启用项;全无启用则 `'system'`。已绑定会话不按启用过滤(AC-R10)。删除也改写**只**适用于系统默认;角色与工作区覆盖删除时清空(AC-R33)。
- **AC-R3** — 加载与保存都归一化:按厂商校验,无 id 则铸造,重复 id 与未知厂商丢弃。无有效项则合成 claude + CLI 登录兜底,注册表永不为空。残留内联连接提起为具名上游后擦除,再派生连接标签。结果回传。
- **AC-R7** — 注册表与按会话绑定分别持久化;失败降级到默认,c3 仍能启动。
- **AC-R10** — 列表消费方(参与者、投票者、降级链、默认选择器)只取已启用。启动解析不按启用过滤,已绑定禁用项仍能启动。该保证不及于空组(AC-R27)。
- **AC-R11** — 图标纯展示,不影响启动或列表资格。
- **AC-R12** — 档案按厂商判别;未知厂商在归一化时丢弃。
- **AC-R13** — 连接标签只读派生:cursor 恒为 CLI 登录;有上游引用则为经提供方,否则 CLI 登录。残留档案字段不是派生输入。模型仍独立覆盖。
- **AC-R20** — 列表顺序由用户排列,归一化为紧凑序号;合成兜底置顶。降级链自有顺序,不跟列表重排。启动按 id 解析,不按位置。
- **AC-R22** — 可解析的配额重置:立即禁用该档案,并登记一次性恢复。写入走与手动停用相同的归一化。无法解析则不自动恢复,既有错误路径不变。

### 具名上游

凭证与端点从档案抽到可复用的提供方;多档案共用一条。内置模型候选离线、不联网发现,是建议不是白名单。

- **AC-R5** — 模型是独立覆盖,空则不覆盖。档案自身不携带连接。
- **AC-R32** — 端点模板只补空槽,已填保留。不是白名单,也不作运行时兜底。

### 连接与探测

- **AC-R15** — 经提供方的 **codex** 走 vendor 中立 relay,真钥不到子进程。见 [ADR-0029](../../architecture/adr/0029-vendor-neutral-relay-and-agent-group-failover.md) 与 [relay 架构](../../architecture/relay-architecture.md)。
- **AC-R30(连接解析)** — 启动与试算同一套:(1) cursor 恒 CLI 登录;(2) 无上游引用 → CLI 登录;(3) 引用不存在 → 回落 CLI 并告警,且**不开**沙箱钥匙串;(4) 上游暂停 → 明确失败,不静默换连;(5) 否则取该厂商支持的第一个有地址的协议槽;(6) 全无地址 → 回落 CLI 并告警。不做跨协议借连。档案残留字段不是连接来源。沙箱是否开钥匙串问本次解析是否为空连接。
- **AC-R31** — 可达性由服务端探测:已存钥只配已存地址,草稿钥只配草稿地址。过管理员门。出网面见 [SEC-15](../../non-functional/security.md)。与测速不同,不消耗生成额度。
- **AC-R36** — 测速是对**已保存**上游的真实生成采样,须先确认代价。生命周期归服务端;关窗不停,显式中断才停。历史只增,提供方是弱引用。过管理员门。未保存的上游不可测。

### 分组与回退

- **AC-R19** — 「同厂商、已启用、除当前外」是切换、降级链与共识投票的共用候选。运行时如何切换与降级见 [agent-session](../core/agent-session.md)。无同伴则不提供切换器。
- **AC-R27** — 角色可指向虚拟组。八个角色同一解析入口;绑的是组,每次运行再展开成员。跟随默认且默认是组时,按组解析,不得按 id 找不到就跳过。空组(无启用成员,或该厂商运行时不可用)**明确失败**,不回落、不留半成品。重新打开已有会话是恢复,不受此限。合成兜底只留给注册表空/损坏。组内回退见 [relay 架构](../../architecture/relay-architecture.md)。评审/修复只取代表成员做种子,不做组游标。
- **AC-R28** — 分组以容器编辑,不手输组名凭空造组。组身份是 `(厂商, 组名)`,一容器一种厂商;不同厂商可同名、互不干扰。可见顺序即回退顺序。解散只清空分组,不删档案。

### 运行时门控

- **AC-R26** — 新开某厂商一轮只看运行时是否可跑,与诊断用的 CLI 事实分开。CLI 版本见 [system-setting](system-setting.md)。已配置为该厂商的档案保持可选,避免界面改掉既有引用。冷启动的两条引导都只对管理员成立,非管理员一律不弹:无真实档案带到配置入口(Agent Tab);有真实档案但没有一条的厂商当前可跑时带到运行时(Runtime Tab)。运行时门的判据只看已配置的真实档案里有没有一条的厂商可跑,与可下载的托管 CLI 是否齐全无关;合成兜底档案两条分支都不算真实档案。各至多一层,判定一次,整页刷新才再判定;与空工作区门不叠加,见 [web-console](../core/web-console.md)。

### 一键自动配置

- **AC-R29** — 尚无真实档案(空,或仅合成兜底)时,可为每个可用且尚无 CLI 登录型档案的厂商各建一条,立即落库,随后走与保存相同的归一化。只建 CLI 登录型。零结果须区分「无可用厂商」与「已覆盖」。过管理员门。存在任一真实档案则不提供入口。

### 默认与专用路由

角色空值跟随默认,存储保持为空、从不自动填。指向已禁用则改写为下一启用项;指向已删除则清空回跟随。

- **AC-R21** — 工具:后台工具会话与完成度/命名,共用同一解析。
- **AC-R23** — 意图沟通:只绑新建;已跑会话恢复冻结绑定,改角色不换绑。
- **AC-R24** — 规格编写。规格审核同一哨兵,无独立编号。
- **AC-R25** — 自动化:只为新建表单做种,记录存创建快照,不进运行时路由。
- **AC-R34** — 评审/修复:种子角色,不绑会话。队列接力不读工作区评审/修复覆盖;改设置不影响在途阶段。无可用则明确失败,不读作「不需要评审」。
- **AC-R35** — 工作:无显式选择的 work 会话。工作区 work 恒先于系统 work;与默认的先后同 AC-R33。不新增会话种类。
- **AC-R33** — 工作区默认与角色:空=继承(省略键,不快照)。禁用改写,删除丢键;系统保存时清理全部工作区悬空引用。工作区**显式默认**时工作区层优先(工作区同名角色 → 工作区默认 → 系统同名角色 → 系统默认 → 兜底);**继承**时系统角色优先(系统同名角色 → 工作区同名角色 → 工作区默认 → 系统默认 → 兜底)。运行时角色保留组与空组硬失败;自动化/评审/修复只做种子。
- **AC-R8** — 新会话权限模式由工作区按厂商做种,见 [workspace-setting](workspace-setting.md)。此后按会话变更不改它。
- **AC-R9** — 讨论每阶段轮次上限由工作区持有,见 [workspace-setting](workspace-setting.md)。讨论引擎读取。

### 每会话绑定

- **AC-R4** — 未绑定会话以默认智能体启动。
- **AC-R6** — 待定 id 读意图,真实 id 读事实;事实缺失读该会话投影行,再无才默认。待定不走投影兜底。
- **AC-R16** — 双键绑定([ADR-0015](../../architecture/adr/0015-session-agent-binding-vendor-ownership.md)):待定意图可变;首次运行复制为事实并冻结厂商,意图丢弃。冻结幂等。运行时重新赋键见 [agent-session](../core/agent-session.md)。
- **AC-R17** — 冻结后厂商不可变;同厂商可换绑,跨厂商拒绝。过期意图只清意图空间,不产生孤儿事实。
- **AC-R18** — 创建可指定智能体为意图,省略则 Auto。默认变更不追溯已绑定会话。

## Domain events

消费 `get_settings`、`save_settings`、`auto_configure_agents`、`probe_model_provider`、`model_provider_speed_test`。发出 `settings`、`auto_configure_agents_result`、`model_provider_speed_test_result`。形状见[共享协议](../../shared/api-conventions/websocket-protocol.md)。工作区覆盖的读写属 workspace-setting。

## 数据模型

### Agent

一次启动档案:厂商无关的公共外壳,加上按厂商判别的配置。`vendor` 决定启动哪个客户端。连接不在档案上——引用一条 ModelProvider,或走该厂商 CLI 登录;连接标签只读派生。`model` 在任一连接来源下都是独立覆盖。

不变量:

- 无受保护单例。注册表空或损坏时合成 id `'system'`、claude、CLI 登录的兜底。
- `enabled` 缺省为启用;列表消费方只取已启用,启动解析不按启用过滤。
- `group` 可选。非空则归入 `(vendor, group)` 组,相同组的启用档案按列表顺序构成可回退候选,暴露为虚拟引用。不同厂商可复用同一组名。成员可混经提供方与 CLI 登录。组模型见 [relay 架构](../../architecture/relay-architecture.md)。
- cursor 不引用提供方,连接标签恒为 CLI 登录。

零或多个会话绑定到一个 Agent;未绑定的会话使用默认智能体。

### ModelProvider

一条具名上游,任意多个 Agent 通过引用共用。轮换凭证或迁移端点只改这一条。可暂停:引用它的启动明确失败,数据保留。

不变量:

- 账户级钥覆盖本提供方全部协议地址。
- 协议槽按 Agent 所属厂商的支持顺序取第一个有地址的。cursor 当前不绑提供方。
- `vendor` 声明线那头是谁家的模型,与 Agent 的启动厂商不是一回事。内置模型清单离线、不联网发现,与自有条目合并后只是建议,不是白名单。
- 创建所用端点模板只作溯源;运行时不读。空槽可按模板补齐,已填保留。

### 会话绑定

按会话的双键空间([ADR-0015](../../architecture/adr/0015-session-agent-binding-vendor-ownership.md)),与注册表的每会话模式分离。

- **意图** — 尚未运行的会话所期望的智能体;可变,无厂商。过期只清意图。
- **事实** — 真实会话实际所用的智能体 + **冻结的**厂商。缺失则读投影行,再无才默认。

不变量:首次绑定把意图复制为至多一个事实并丢弃意图;此后该会话厂商不可变,只允许同厂商换绑。

### 测速运行

对一条已保存 ModelProvider 的一轮真实生成采样。与连通性探测不是一事。

不变量:收束后只增;进行中的进度不落库。提供方是弱引用,展示名快照使改名或删除后历史仍可读。对比是已存汇总的原样投影,不重算。

## 协作

**agent-session.** 每次运行向本域解析启动覆盖(连接与模型)与同厂商候选。运行、降级与手动换绑在该域;本域不复制其规则。

**session-registry.** 提供会话 id。绑定与注册表的每会话模式同属会话作用域,但各写各的键。

**workspace-setting.** 工作区默认与角色覆盖存在该域;本域按 AC-R33 / AC-R35 解析。权限模式与讨论上限不在本域。

**system-setting.** 宿主 CLI 版本与诊断事实在该域。本域只取运行时是否可跑,用来门控新开一轮与自动配置。

**web-console.** 渲染档案、上游、默认与角色。浏览器提示不是关卡。

**sandbox.** 是否开宿主钥匙串问连接解析是否为空;悬挂引用的 fail-soft 回落不打开钥匙串。

**auth.** 写系统配置、自动配置、探测与测速过管理员门。

**relay.** 经提供方的上游走 vendor 中立 relay,真钥留在本进程。组内回退见 [ADR-0029](../../architecture/adr/0029-vendor-neutral-relay-and-agent-group-failover.md) 与 [relay 架构](../../architecture/relay-architecture.md)。

## 关键取舍

**注册表永不为空,但无受保护单例。** 删光则合成兜底,而不是锁死一条不可删的系统档案。

**已绑定不锁死,空组硬失败。** 具体档案禁用后仍可启动;角色指向空组是配置错误,必须暴露。

**悬挂回落,暂停失败。** 引用不存在则告警并走 CLI,避免陈旧引用卡死;运维暂停则必须点名失败,否则「停用」无意义。fail-soft 不开钥匙串。

**意图与事实分开,厂商冻结。** 待定期望可改;首次运行落下事实后厂商不可变,同厂商才可换绑。见 [ADR-0015](../../architecture/adr/0015-session-agent-binding-vendor-ownership.md)。

**继承省略键,不快照。** 工作区空值跟随上级;写入当时的系统值会冻住继承。删除清空角色,禁用才改写到邻居。

**自动配置只在尚无真实档案时出现。** 只建 CLI 登录型;自定义上游无法从探测推断。

**可用性与诊断分开。** 门控只问能不能跑;路径与版本留给 system-setting,以免门控随诊断字段漂移。

## 非功能

提供方密钥按密文存放,见 [security](../../non-functional/security.md) SEC-13。探测出网见 SEC-15。持久化失败则降级到默认,仍能启动。
