# c3 特性清单

c3（code creative center）全部能力的树状索引，每行一句话。按业务组与能力域组织，与 [`domains/`](domains/) 对应。详细行为见各域 `{domain}.md`；协议约定见 [`websocket-protocol.md`](shared/api-conventions/websocket-protocol.md)。

```
c3
│
├── core — 智能体循环：用户说 → 智能体做 → 用户看并操控
│   │
│   ├── agent-session 智能体会话                  # 驱动厂商智能体完成单次 run
│   │   ├── 运行生命周期                          # 接收 prompt、流式输出，直至完成、出错或中止
│   │   ├── 活动状态注册表                        # 进程内当前活动事实，带租约续约，与 Runtime 正交，可从事实源重建
│   │   ├── 角标投影                              # 从活动集合与三类 attention 集合增量维护 Workspace 摘要
│   │   ├── 活动快照与增量                        # ready 后下发可见工作区摘要，变化时推送 revision 增量；空闲不点查计数
│   │   ├── 运行日志                              # 每个 run 留下开始与落定记录，失败另记阶段
│   │   ├── 消息规范化                            # 把厂商消息译为协议事件
│   │   ├── 权限模式                              # 按厂商模式目录解释为中立网格
│   │   ├── 取消中止                              # 用户停止或删除时干净中止在途 run
│   │   ├── 历史续传                              # 每轮持久化，刷新可回放
│   │   ├── 多厂商                                # 同时支持 Claude、Codex 与 Cursor
│   │   ├── Codex 令牌桥接                        # 启动时注入宿主 gh 令牌，已有则不覆盖
│   │   └── Codex 子进程回收                      # 异常结束回收本轮进程树；resume 遇残留写锁且能证明归属才自动杀并重试一次
│   │
│   ├── permission-gateway 权限网关               # 有副作用的工具须过此门
│   │   ├── 权限拦截                              # 敏感工具运行前暂停
│   │   ├── 人工路由                              # 转发到浏览器，阻塞等待裁决
│   │   ├── 策略自动裁决                          # 已存规则与模式可在询问人前决定
│   │   ├── 运行中止语义                          # run 中止即拒绝在途权限请求
│   │   └── 审计留痕                              # 记录谁在何时决定了什么
│   │
│   ├── session-registry 会话与工作区目录         # 工作的档案柜与调度器
│   │   ├── 工作区注册                            # 唯一且不可变的名称、磁盘路径、最近访问顺序
│   │   │   └── 目录点选                          # 新增路径用本机目录对话框选择
│   │   ├── 会话目录                              # 按业务种类增删列；规格撰写与评审同列展示
│   │   ├── 最近访问排序                          # 维护会话列表的最近使用顺序
│   │   ├── 历史持久化                            # 转录持久化，重连即可回放
│   │   ├── 模式记忆                              # 记住每个会话上次的权限模式
│   │   └── 游标分页                              # 会话列表按种类分页加载
│   │
│   ├── web-console Web 控制台                    # 人观察与操控智能体的浏览器窗口
│   │   ├── 活动流                                # 渲染文本、工具活动、权限提示与共识
│   │   ├── 提示输入                              # 提交或排队；支持斜杠命令、语音与图片
│   │   ├── 待发队列                              # 运行中可改可删待发消息，结束后自动发出
│   │   ├── 权限 UI                               # 允许或拒绝、逐题作答、展示共识
│   │   ├── 控制面                                # 切换模式与智能体，停止、继续；崩溃可重试
│   │   ├── 会话与工作区                          # 增删改名与选择；桌面端竖条列出工作区
│   │   ├── 冷启动引导                            # 首次进入按条件引导配置，不叠加，刷新才再判定
│   │   ├── 双视图                                # 工作区与工作台两大视图
│   │   ├── 移动端                                # 小屏分层进入，避开软键盘与安全区
│   │   ├── 富文本渲染                            # 渲染 Markdown、代码高亮与图表
│   │   ├── 分享链接                              # 一键复制带深链的标题
│   │   ├── 运行日志页                            # 独立页面查看服务日志，默认同步最新
│   │   ├── 进度遮罩                              # 启动开发、写规格、建意图或建 PR 时分步遮罩
│   │   ├── 更新胶囊                              # 顶栏展示自更新进度，管理员可确认重启
│   │   └── 国际化                                # 英、中、日、韩、俄与日期数字本地化
│   │
│   ├── intent-management 意图管理                # 把想法变成可验证、可追踪的账本并驱动生命周期
│   │   ├── 意图账本                              # 按工作区持久化；确认后写入，亦可直接新建草稿
│   │   ├── 意图精炼                              # 只读智能体把想法拆成可验证条目
│   │   ├── 影响范围等级                          # 与优先级正交，并联动规格与评审闸门
│   │   ├── 正文直接编辑                          # 草稿与待办可改正文，进行中及之后锁定
│   │   ├── 规格撰写与批准                        # 开发前生成规格并经人批准，改写使批准失效
│   │   ├── 每意图规格模式                        # 可选择是否需要规范；高影响强制需要
│   │   ├── 规格只读审核                          # 独立会话只读评审，结论绑定当前内容；可回放不可续跑
│   │   ├── 规格直接编辑                          # 开发未起步且无在写规格时可改规格正文
│   │   ├── 意图开发                              # 已有会话则挂接或续跑，否则新建；回合用尽可重启
│   │   ├── 意图交付                              # 追踪分支、提交与 PR；手动开发结束可建 PR
│   │   ├── WorkNote 历史                         # 只增不改的工作笔记，供后续智能体阅读
│   │   ├── PR 评审修复结论                       # 意图级保留审评与修复结论及轮次，与规格审核、托管状态、生命周期各自独立
│   │   ├── 基准分支                              # 意图建在哪条分支上落为快照，不追随后续推进
│   │   ├── 失败修复指引                          # 按失败原因给出指引与重试，不代为改仓库或凭据
│   │   ├── 手动建 PR                             # 人工创建意图 PR，与顾问入口共用同一套闸门
│   │   ├── 关联外部 PR                           # 创建失败且尚无活跃 PR 时可关联已有 PR
│   │   ├── PR 更新复位                           # 更新成功时把已关闭或失败的记录重新标为审查中
│   │   ├── PR 落地自动完成                       # 审查了结且 PR 已合并时自动标完成
│   │   ├── 意图依赖                              # 看产出是否已在我的基线上；可说明阻塞、指向前序，并一次性放行
│   │   ├── 危险动作                              # 取消与删除收入溢出菜单并二次确认
│   │   ├── 沟通会话                              # 意图右侧可建多条沟通会话
│   │   ├── 自动化队列                            # 勾选的意图按优先级与依赖自动开发
│   │   │   ├── 调度、失败与挂起                  # 对账账本与运行；单失败则退避挂起，下游仍被挡住
│   │   │   ├── 权限交回人工                      # 权限等待超时只挂起并待办，不代答
│   │   │   ├── 规格阶段自治                      # 撰写、审核、有限返工；触顶转人工，可选机器批准
│   │   │   ├── 并发与观测                        # 限制同时开发数；决策可查，久无进展则提示
│   │   │   ├── 队列页与夺回                      # 展示阻塞原因，可暂停、跳过、解除挂起
│   │   │   ├── PR 评审修复接力                   # 建 PR 后自动评审修复；标题栏也可人工发起
│   │   │   └── 顾问工具                          # 决策点可唤起顾问查询、停 run、建 PR、催人
│   │
│   ├── delivery 交付                             # 一批意图共同集成并进入主线
│   │   ├── 写入窗口                              # 验证期间关联意图不得再开写入会话
│   │   ├── 会话与工作树                          # 启动时选定所属交付；新工作树以基准分支为根
│   │   ├── 同步主线                              # 集成期间可把主线合入交付分支，冲突不代解
│   │   ├── 账本与状态                            # 规划到已交付受控推进，非终态可取消；结束后可删本地分支
│   │   ├── 守卫与进度                            # 分支就绪、PR 合入、人工验证、合并成功；以合入数呈现
│   │   ├── 分支初始化                            # 创建与建分支分步；多仓工作区不能建交付
│   │   ├── 意图关联                              # 建边不改投已有 PR；已合并不可解，解除先关未合 PR
│   │   ├── 当前意图独立交付                      # 意图侧一键建交付、关联并初始化分支
│   │   ├── PR 落点                               # 已关联则打向交付分支；关联时分叉只提示
│   │   ├── 交付页                                # 顶栏入口，角标只计需人处理者
│   │   ├── 交付 PR                               # 已验证后建到主线的 PR，从不代合
│   │   ├── 合并结果                              # 冲突回退；CI 或审批受阻则状态不动；已在主线则直接交付
│   │   ├── 操作日志                              # 合法动作各记一行；托管平台已合未确认时显示等待
│   │   ├── current-branch 降级                   # 当前分支模式下只作聚合视图
│   │   ├── 合并目标提示                          # 首次建交付时提示自动化需区分合并目标
│   │   └── 事件与只读查询                        # 生命周期可订阅；自动化与外部可查不可写
│   │
│   ├── discussion 多智能体讨论                   # 多智能体与人圆桌讨论，可转为意图
│   │   ├── 讨论账本                              # 按工作区持久化主题与参与者
│   │   ├── 多智能体轮流                          # 组织者编排参与者轮流发言
│   │   ├── 人类参与                              # 人可发言、暂停、停止；停止后不可恢复
│   │   ├── 参与者定向                            # 创建时勾选参与智能体，组织者始终在场
│   │   ├── 研究会话                              # 会前研究是正式会话，可回放与追问，仍只读
│   │   ├── 讨论转意图                            # 把结论转化为意图
│   │   ├── 讨论工具                              # 自动化可查找、查看、开始与继续讨论
│   │   └── 生命周期事件                          # 开始与结束各发一次，可供订阅
│   │
│   ├── automations 自动化                        # 按计划或事件跑智能体工作
│   │   ├── 自动化注册                            # 按工作区持久化触发器、任务与工具策略
│   │   ├── 定时触发                              # 按计划触发，可限定每日时段
│   │   ├── 事件触发                              # 响应系统事件并按条件过滤
│   │   ├── 链式触发                              # 自动化可触发另一条自动化
│   │   ├── 执行记录                              # 每次运行留下起止与结果供审计
│   │   ├── 自动化会话                            # 独立会话；运行中可看实况，结束后可回放
│   │   ├── 执行身份                              # 新建用默认智能体；三厂商均可执行，找不到则失败
│   │   ├── 工作台工具                            # 按需挂载意图、交付、讨论等工具
│   │   └── 网络开关                              # 可写沙箱下可打开网络，默认关闭
│   │
│   ├── files 文件浏览                            # 浏览器里只读浏览仓库，并可就代码提问
│   │   ├── 仓库浏览                              # 列当前工作树、读文本、有界搜索
│   │   ├── 文件树状态                            # 标出改动、未跟踪与暂存，可见时刷新
│   │   └── 代码域会话                            # 内嵌工作会话就代码提问，可新建或重置
│   │
│   ├── workcenter 工作台                         # 全局运行总览与通知处理
│   │   ├── 工作区总览                            # 各工作区运行规模与自动化总闸，管理员可开关
│   │   ├── 用户通知                              # 聚合事件列表与详情，可按状态筛选分页；入口角标读权威待办总数
│   │   ├── 权限作答                              # 在工作台直接允许、拒绝或答题
│   │   ├── 共识留痕                              # 自动记录的投票与裁决可回看
│   │   └── 溯源跳转                              # 从通知跳到对应意图或会话
│   │
│   ├── sandbox 沙箱                              # 入选会话的 run 进进程级隔离
│   │   ├── 进程级隔离                            # 限制可见目录，无容器、无凭证注入
│   │   ├── 放行范围                              # 执行根可写、源只读、规格目录可写；工作区可再挂载
│   │   ├── 代理与认证                            # 宿主代理一并使用；订阅登录可用钥匙串
│   │   ├── 会话种类                              # 工作区指定哪些会话种类进沙箱
│   │   └── 驱动                                  # 自动安装隔离驱动；不可用则失败不裸跑
│   │
│   ├── auth 鉴权                                 # 连接过身份门，改全局配置过管理员门
│   │   ├── 登录与令牌                            # 校验身份并签发会话令牌
│   │   ├── 连接与管理员门                        # 未认证不得连接；仅管理员改全局配置
│   │   ├── 多账号                                # 多账号目录，首位创建者为唯一管理员
│   │   ├── 主体与范围                            # 缺省为本地主体；工作区默认拒绝，管理员与本地恒全部
│   │   └── 调用卡口                              # 每次调用求交范围；授权变更使既有会话失效
│   │
│   ├── memory 工作区记忆                          # 工作会话跨轮次记下偏好、约束与教训
│   │   ├── 检索与写入                            # 仅工作会话可搜索与改记忆，标准权限门免确认
│   │   ├── 设置页查阅                            # 工作区设置可查阅并软删，不提供新建与编辑
│   │   ├── 同名与矛盾                            # 同一标题视为一条；系统不合并正文
│   │   ├── 写入边界                              # 超限报错；凭据与代码产物拒写
│   │   └── 软删回收                              # 删除先改状态，到期再清除
│   │
│   ├── im-robot 聊天机器人                        # 群里提问、无人值守跑一轮、最终回答发回群
│   │   ├── 部署级出入口                          # 配置跨工作区共享，每次调用仍求交作用域；平台策略在中性层
│   │   ├── IM 身份绑定                           # 本人按平台绑定；未绑定只收引导
│   │   ├── 能力与外发                            # 分档上限；默认停用，启用须管理员确认并审计
│   │   ├── 只发最终回答                          # 回合结束才外发正文，执行中仅固定进度提示
│   │   ├── 出站与隔离                            # 唯一出站入口；本地文件只读运行目录；每回合进程隔离
│   │   ├── 无人值守                              # 交互工具直接拒绝，见授权请求即结束回合
│   │   ├── 工具权限                              # 与自动化共用网格；勾选账本写工具不放开本地沙箱
│   │   ├── 响应与对话                            # 群默认需 @；同一发送者串行，问答成对保留
│   │   ├── 运行诊断                              # 出入站记元数据，不记正文与验证码
│   │   └── 飞书应用开通                          # 管理员可扫码建应用并回填凭据，失败不脏填
│   │
│   └── external-mcp 外部 MCP                     # 外部智能体凭长期钥匙访问本部署
│       ├── 接入与凭据                            # 单一路径接入，只认授权头，凭据不放 URL
│       ├── 工作区与求交                          # 初始化钉定工作区；每次调用重算范围
│       ├── 本机与暴露                            # 回环无管理员可免钥匙；对外暴露却无管理员则拒绝
│       ├── 工具目录                              # 管理员勾选，新钥匙默认只给读；未授权不可调用
│       ├── 目标与自检                            # 写目标须在可见工作区内；可查范围不含密钥
│       ├── 写调用审计                            # 每次写尝试记结果，不含入参与密钥
│       └── 规范对齐                              # 与内部面同一传输形态；差距见 [合规说明](domains/core/mcp.md)
│
├── settings — 塑造智能体循环的配置；作用域分系统、工作区、个人
│   │
│   ├── agent-config 智能体配置                   # 档案目录与会话用哪个智能体
│   │   ├── 智能体档案                            # 按厂商持久化名称与模型，可增删、排序、启停、复制
│   │   ├── 具名上游                              # 连接抽成可复用提供方；内置离线模型候选
│   │   ├── 连接与探测                            # 经提供方或 CLI 登录；可探测可达性与测速
│   │   ├── 分组与回退                            # 同厂商编组按序回退；亦可配置降级链
│   │   ├── 运行时门控                            # 宿主 CLI 不可用则不能新开该厂商一轮
```
