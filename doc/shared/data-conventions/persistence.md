# 配置持久化

配置只有实例库 `c3.db` 一处事实源（[ADR-0042](../../architecture/adr/0042-configuration-in-database.md)）。表结构见 [database/tables.md](../../../database/tables.md) § config。

## 作用域即写入边界

五类作用域彼此独立，一次写入只触及一类：系统、工作区、个人化、会话事实、MCP 钥匙。保存一类不可能改到另一类，也不可能改到同一类的另一分组。写入方不必带上它不拥有的字段；系统保存不触及它不拥有的键。

- 整体保存以存储为权威重读合并，不以本进程缓存为基准：两个 c3 进程共用同一文件时，一方的保存不会把另一方刚写入的值静默回退。
- 读路径使用进程内缓存，由本进程写入刷新；缓存不跨进程失效。
- 数据库不可用时读退化为默认值、写失败，不静默丢写。

## agent apiKey 落盘加密

密钥在磁盘上是密文，读出即解密——**内存恒明文、磁盘恒密文**。密文强度为混淆级，见 [security · Agent apiKey 静态加密](../../non-functional/security.md#agent-apikey-静态加密)。
