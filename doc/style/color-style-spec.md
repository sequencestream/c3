# 风格设计规范

控制台视觉契约。合法主题 id 以本文为准；配色取值在设计令牌里，本文不列色值。个人化设置只接纳合法 id，见 [personalized-setting](../domains/settings/personalized-setting/personalized-setting-spec.md)。

## 设计原则

- **沉浸**：界面退后，内容向前；去掉不必要的分割线、边框与装饰。
- **轻量**：半透明材质、弥散阴影、柔和圆角。
- **顺畅**：动效服务于反馈，不打断心流。
- **冷静**：深色为默认基底，强调色高饱和但克制。
- **疏朗**：信息密度低于传统 IDE，留白充裕。

## 主题

主题是可扩展注册表，不是页面里的二选一开关。每项声明稳定 id 与展示名（展示名走 i18n，是普通 UI 文案）。界面上的主题选择器由注册表生成，不另存一份清单。

当前三套：`dark`（默认）、`light`、`solarized-light`。运行时把选中的 id 写入 `data-theme`；未知、缺失或损坏的值归一为 `dark`。主题只映射不配色。扩主题只需注册表加一项并配上同名令牌覆盖，选择器与运行时不改。

主题是显式个人化选择，不读 `prefers-color-scheme`，不跟随操作系统。未走设计令牌的硬编码颜色在非默认主题下会显形，按缺陷修复，主题机制不兜底。

## 可访问性

- 文字与其真实承载背景对比足够；半透明与叠加按合成后的颜色衡量。
- 状态不只靠颜色传达。
